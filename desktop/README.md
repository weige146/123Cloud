# 123Cloud Desktop（桌面客户端）

123Cloud 的 Windows / macOS 桌面应用：Electron 壳 + Python 后端（FastAPI）+ Vue 3 前端。把网盘搬运、投稿发布、影库管理收进一个客户端，同时作为本机 HTTP 服务与油猴脚本「123 助手」联动。

- 资源搬运：115 分享链接 / 目录批量搬到 123 云盘（或反向搬回 115），断点恢复、多账号轮换
- 频道投稿：配合 Telegram 投稿机器人，自动生成投稿草稿（TMDB 识别、豆瓣评分、海报），确认后发布
- 影库管理：秒传文件解析进本地数据库，分类浏览、拼音搜索、一键转存
- 本机服务：为油猴脚本提供投稿、影库与会话中转接口

## 功能

### 115 → 123 搬运

把 115 分享链接 / 目录自动搬到 123 云盘，六阶段管线：解析 → 规划 → 秒传 → 离线下载 → 统一等待 → 收尾。

- SHA1 / MD5 秒传优先，秒不动的自动滚动提交 123 离线下载（并发 1-5 可配，完成一个补交一个）
- 断点恢复、超时自动重提、任务去重、失败重试
- 115 多账号 Cookie 池轮换，失效自动冷却换号
- 完成后可选自动删除 115 源文件（独立开关，安全闸门保护）

### 123 → 115 反向搬运

把 123 云盘文件反向搬回 115：按内容指纹反查 115 SHA1，直接秒传入 115。

### 共享 SHA1 秒传池（默认启用）

所有用户的搬运成果（内容指纹 + 文件名）自动进入共享池：你搬过的内容，别人搬运时直接秒传命中，反之亦然。

- 安装即用；每个用户独立 API Token，独立限流、可单独撤销
- 管理员 Token 额外开放「秒传池」入口：搜索共享池内容目录，勾选后 SHA1 秒传到指定 123 文件夹
- 密钥在「设置 → 秒传池密钥」管理：默认用安装包内置分发 Token（只加速搬运），粘贴管理员 Token 解锁搜索
- 共享池命中不写本地学习表、不自动删除 115 源文件（防投毒护栏）
- 服务异常自动熔断降级，只影响加速，不影响搬运；本地学习表始终兜底

### Telegram 投稿机器人

- 123 分享 / 秒传链接自动生成投稿草稿：TMDB 识别、豆瓣评分、海报、资源信息自动补齐
- 按发布组规则路由到对应频道，草稿确认后一键发布
- 应用内 TG Session 登录，草稿预览按钮交互
- 配套油猴脚本在网页端触发投稿与搬运（见 [`油猴脚本/`](../油猴脚本/123-helper/123-helper.user.js)）

### 115 助手

- 单账号提交离线磁力 / ed2k 任务，定时清理 115 回收站
- 扫码获取 115 Cookie，写入助手或搬运 Cookie 池

### 影库

「影库」页把影库文件解析进本地数据库（`cloud123.db`，WAL），源文件导入后删掉仍可查询，并开放 HTTP 接口给油猴脚本随时搜索转存。

- 导入方式：系统文件选择器多选，或文件夹批量递归导入（迁移老数据用，不驻留监控）
- 支持格式：123FastLink 标准 JSON、123pan-strm 备份、V1/V2 秒传文本、`.123share`、`[tmdb-N]` 第三方标记
- 大文件流式导入：GB 级 / 千万级条目的秒传 JSON 按块流式解析入库，内存占用与文件大小无关；非影库文件自动跳过，不算失败
- 视频扩展名：内置 PT/BT 站主流格式（mkv/mp4/ts/iso 原盘/m2ts/rmvb 等）；影库设置里可自定义补充扩展名，用于判定导入 JSON 里的文件条目是否计入作品视频数，重新导入生效
- 来源管理：每个文件一个来源，可单独删除（级联移除其作品与文件）；同一作品重复导入自动跳过，同名来源重导更新内容
- 导出：秒传 JSON 由服务端直接写进「导出目录」（可固定），不走浏览器下载
- 转存到云盘：作品 / 勾选文件走 123 OpenAPI 秒传（需先在设置页授权），按影库目录结构逐级建目录
- 搜索：全部走 SQL，片名支持拼音与首字母，分类 / 统计现算，SQL 分页；海报与 TMDB 简介由后端代理并缓存

### 运行日志

「设置 → 运行日志」实时查看（内存环形缓冲最近 10000 行），同时轮转落盘（5MB × 3 份）。

### 软件更新

自动检测 GitHub 新版本（启动 10 秒后查一次，之后每 6 小时一次），发现新版本后台自动下载，「设置 → 软件更新」显示进度，下载完成后点「重启并安装」完成升级（Windows 不点也会在退出时自动安装）。升级只替换应用本体，配置与数据不动。

- 1.4.4 及更早版本没有内置更新组件，提示「未包含自动更新组件 / 请到发布页下载」属预期，手动安装一次新版本即可
- Release 里的 macOS `.zip` 是自动更新专用产物，手动安装下载 `.dmg` 即可

## 使用方式

### 安装

从 [Releases](https://github.com/weige146/123Cloud/releases) 下载对应平台安装包：

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| macOS (Apple Silicon) | `123Cloud-<版本>-macOS-arm64.dmg` | ad-hoc 签名，首次打开右键 →「打开」 |
| Windows x64 | `123Cloud-<版本>-Windows-x64.exe` | 未签名，SmartScreen 点「更多信息」→「仍要运行」 |

### 首次配置

| 功能 | 需要准备 | 在哪里配置 |
| --- | --- | --- |
| 投稿机器人 | 123 云盘账号登录；TMDB API Token；Telegram Bot Token | 客户端内登录 123 → 设置页 |
| 频道发布 / 通知 | Telegram Bot Token + API ID / API Hash | 设置页 |
| 115 → 123 搬运 | 123 开放平台 clientID / clientSecret；115 Cookie（可多账号池） | 「搬运」设置 |
| 115 助手 | 115 Cookie（扫码获取） | 「115 Cookie」页 |
| 影库接口 / 一键投稿 | 无需额外凭据；建议固定服务端口 | 「设置 → 服务端口」 |
| 配套油猴脚本 | Tampermonkey + 脚本设置里填客户端地址 | 见[油猴脚本说明](../油猴脚本/123-helper/README.md) |

典型路径：

1. 启动客户端，设置页登录 123 云盘账号，填 TMDB Token 与 Telegram 凭据；
2. 搬运：到「搬运」设置填 123 开放平台 clientID / clientSecret（[123 开放平台](https://www.123pan.com/developer)创建应用获取），加 115 Cookie；
3. 「设置 → 服务端口」固定端口，把 `http://127.0.0.1:<端口>/api/submission/submit` 填进油猴脚本「投稿地址」，网页端即可一键投稿；
4. 影库文件在「影库」页导入后，油猴脚本「影库接口地址」填 `http://127.0.0.1:<端口>` 即可随时搜索转存。

### 窗口与后台服务

- macOS 点红绿灯关闭窗口只销毁窗口，后端与油猴脚本依赖的本机服务继续运行；点 Dock 图标重新打开窗口。Cmd+Q 为完整退出。
- 关闭窗口再打开直接进管理页；若窗口长时间未响应可从菜单退出后重启应用。

## 注意事项与已知限制

- 搬运必须在「搬运」设置填入 123 开放平台的 clientID / clientSecret，否则离线下载任务无法提交。
- 后端只监听 `127.0.0.1`，请勿将端口暴露公网；油猴脚本与客户端需在同一台电脑。
- 应用保存网盘登录态、Cookie、Telegram Session 和 API 凭据，请勿把数据目录交给不可信的人。
- 安装包未公证：macOS 首次打开右键 →「打开」，提示已损坏执行 `xattr -cr "/Applications/123Cloud.app"`；Windows 在 SmartScreen 点「仍要运行」。
- Windows 包无法在 macOS 交叉构建（PyInstaller 限制），由 CI 在 Windows runner 构建。
- 共享秒传池只加速搬运；管理员 Token 才能搜索池内目录。
- `/api/pan/session` 为油猴脚本「登录会话复用」存取网页端会话，鉴权与影库接口同门（配置了影库访问令牌就必须携带）；请勿把服务端口暴露到公网。

## 常见问题

- **115 账号提示失效？** Cookie 过期或被风控，到「115 Cookie」页重新扫码；搬运池里失效账号自动冷却换号，「115 中心」可查看并清除停用限制。
- **投稿草稿没出现？** 油猴脚本「投稿地址」端口与客户端「服务端口」一致、地址带完整路径 `/api/submission/submit`、客户端在运行。
- **影库搜索连不上？** 接口地址端口一致；客户端设置了访问令牌时脚本填同一串。
- **升级后数据还在吗？** 在。登录态、任务记录、影库数据都在本机数据目录，覆盖安装不影响。
- **设置页提示「未包含自动更新组件，请到发布页下载」？** 当前安装的版本早于自动更新组件内置（1.4.4 及更早），到 Releases 手动安装一次新版本即可，之后新版本都能在应用内自动更新。
- **影库导入的 JSON 里有些文件没算进视频数？** 视频按扩展名判定，内置 PT/BT 主流格式；冷门格式在「影库设置 → 自定义视频扩展名」补充后重新导入。

## 开发与构建

```bash
# 后端（Python 3.9+）
cd desktop/backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt -e '.[dev]'
.venv/bin/python -m pytest tests/ -q

# 一键起开发环境（venv 后端 :8321 → Vite :5174 → Electron 窗口）
cd desktop && npm install && npm run dev

# 本地出包：前端 → PyInstaller 侧车 → Electron
cd desktop/web && npm ci && npm run build && cd ..
python3 -m PyInstaller backend.spec --noconfirm --distpath backend-dist --workpath backend-build
npm ci && npm run dist:mac
```

推送 `main` 或打 `v*` 标签后，CI 自动跑测试并在 macOS / Windows runner 出包，tag 推送自动创建 Release。改动先本地打包实测、验收通过后再提交（见根目录 [AGENTS.md](../AGENTS.md)）。
