# 123 助手（油猴脚本）

增强 123 云盘网页端的文件、分享与秒传管理，并可和 [123Cloud 桌面客户端](https://github.com/weige146/123Cloud)联动实现一键投稿。

- 脚本文件：[`123-helper.user.js`](./123-helper.user.js)（版本号以脚本头部 `@version` 为准，勿在文档里手写具体版本）
- 适用页面：123 云盘网页端（123pan.com / .cn 及 123684 / 123865 / 123912 / 123635 等域名）+ 123 公开分享页

## 功能总览

### 文件页增强

- **全盘搜索**：不受当前目录限制，直接搜索整个云盘
- **右键 / 工具栏入口**：批量重命名、媒体整理、文件清理、秒传工具箱、批量分享
- **文件套同名文件夹**：把散落的文件一键包进同名文件夹
- **纯净模式**：隐藏网页端的推广与杂乱元素；紧凑表格行、隐藏「备份」文件夹
- **液态玻璃主题**：跟随系统 / 浅色 / 深色

### 批量重命名

- 规则链自由组合：查找替换（支持正则、区分大小写）、模板编号（`{name}` / `{n}`、起始编号与位数、前后缀）、删除指定文本或位置范围、字符移动、大小写与全角半角转换、空格清理
- 实时预览、保留扩展名、只改文件 / 只改文件夹
- 常用组合保存与载入、重命名历史恢复

### TMDB 媒体整理

- 自动识别电影 / 剧集，按标题或 TMDB ID 搜索，海报墙预览、媒体分组
- **剧集季集校准**：季偏移 / 集偏移手动微调；TMDB 自动校准支持季重映射（发布组按年份编号 vs TMDB 绝对季）、会员版 / 加更 / 先导片等特别篇按期数与播出日期精确匹配、命名季特别篇（如「中医季 药食同源第 1 期」按 TMDB 季名归属目标季）、文件名 `SxxEyy` 显式标记权威匹配
- 变体命名：同集多版本（上/下分部、加更版、衍生段）自动插入变体标记（在季集记号之后、分辨率等参数之前），避免同名冲突；「主标题·命名季」（如 初入职场·中医季）自动按主标题识别 TMDB 剧集；标题里的 `part1` / `第1部分` 分段标记自动剔除（重名冲突时才以 `Part01/Part02` 变体标记区分，避免后写文件被清进回收站）
- 命名模板可自定义字段（标题、年份、分辨率、编码、音轨、发布组……），电影 / 剧集文件名、媒体文件夹（`中文名 (年份) {tmdb-id}`）、季目录模板独立配置
- **自动归类媒体库**：按条件把整理后的文件移动到媒体库目录，兼容 MoviePilot 二级分类（条件 AND / OR / 排除、年份范围、兜底分类）
- 识别词体系：自定义识别词、屏蔽词、特殊发布组别名、自动识别固定映射（分辨率 / 音效 / 编码等）、**特别篇关键词映射**（先导片 / 加更 / 会员版等 17 类触发词，设置里可自行增改别名，类型名也可自由自定义（如综艺衍生段「动脑吧」「体验版」），新叫法不再漏识别）
- 旁挂字幕 / nfo 等附属文件可配置清理，支持移入回收站

### 文件清理

- **条件清理**：后缀名 + 关键词 + 大小范围组合筛选，实时容量统计，勾选后批量删除
- **空目录清理**：递归检测当前目录或全盘空文件夹，批量删除
- 扫描阶段不修改云盘、不自动勾选，确认后才执行

### 秒传工具箱

- **生成秒传**：导出 123FastLink 标准 JSON 与 123FLCPV2 链接（固定 Base62 ETag 的 V2 标准格式），文件夹递归
- **链接 / 文件转存**：支持 123FastLink JSON、V1 / V2 秒传文本、`.123share`，保留目录结构导入当前目录
- **转存秒传（工具栏一键）**：文件页勾选 1 个秒传种子文件（`.123fastlink.json/.txt`）后，工具栏「转存秒传」按钮才出现，点击直接转存，无需打开工具箱；普通文件/多选/文件夹时不显示该按钮，避免置灰按钮点了没反应。选中种子文件点「秒传」打开工具箱也会直接开始导入
- **二级秒传**：在「生成秒传」页签点「生成二级链接（短链）」，整包内容上传为云盘种子文件（`xxx.123fastlink.json`），对外只分享一条 `123FLCPV2$%` 开头的单文件短链接；对方转存时自动秒传种子、读出内容、再转存全部文件。旁边「把已生成链接保存到云盘」可把链接存回云盘。种子默认存在当前目录，可在秒传设置里固定到指定文件夹（数字 ID 或从云盘选择目录）；种子文件请勿删除，否则链接失效
- **自动识别普通 / 二级**：「链接/文件转存」页签的粘贴框、本地文件导入和勾选的云盘文件都会自动判断——单文件且名为 `*.123fastlink.json/.txt` 的种子走二级还原，其余按普通秒传直接转存
- **仅保存链接**：把已生成的秒传链接文本保存为云盘里的文本文件（与「从秒传文件获取」形成 存 ↔ 取 闭环）
- **分享链接生成 JSON**：粘贴 123 分享链接直接递归生成秒传 JSON，无需先转存；支持批量（每行一个链接）
- **拆分 JSON**：按目录层级或按文件数量拆分大秒传文件
- **格式转换**：`.123share` ↔ 标准 JSON 本地互转
- **过滤设置**：生成 / 转存时按扩展名跳过 nfo、图片、字幕等
- 分享口令规范化：拦截官方分享创建响应，统一口令文本格式
- 表格勾选读取升级：直接从 123 页面 React 组件内部状态读取选中文件（含文件指纹），更准更快，页面改版更不易失效；生成秒传时对选中文件少一次接口查询

### 分享与一键投稿

- **批量分享**：每个顶层项单独创建分享（已有相同分享直接复用），永久有效 + 随机口令（有效期、口令长度可配），一键复制全部链接
- **分享页导出 CSV**：把自己分享列表导出表格
- **一键投稿**：分享创建后自动推送到 123Cloud 客户端——别人的分享自动进入搬运队列，自己的分享生成投稿草稿，客户端确认后发布

### 公开分享页增强

- 打开别人的 123 分享链接时：隐藏顶部拉新横幅与会员广告
- 增加「生成秒传 JSON」按钮：无需登录 123 账号，递归读取公开分享生成秒传文件

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 打开 Tampermonkey 面板 →「添加新脚本」，粘贴 `123-helper.user.js` 全部内容并保存；
   （或直接把 `123-helper.user.js` 拖入浏览器，由 Tampermonkey 接管安装）
3. 访问 123 云盘网页版，脚本自动生效。油猴菜单里也有「打开 123 助手设置」「切换页面纯净版」快捷入口。

## 与 123Cloud 客户端配套：一键投稿

脚本可以把网页上创建的分享链接**直接推送为桌面客户端的投稿草稿**，客户端里预览后一键发布到频道。

1. 下载并安装 [123Cloud 客户端](https://github.com/weige146/123Cloud/releases)（保持运行）；
2. 打开客户端 **设置 → 服务端口**，查看当前端口（默认自动分配，也可以在这里固定一个端口）；
3. 在脚本的设置页找到「投稿地址」（`submissionUrl`），填入：

   ```text
   http://127.0.0.1:<客户端端口>/api/submission/submit
   ```

   例如客户端显示端口为 `62156`，则填 `http://127.0.0.1:62156/api/submission/submit`。
4. 之后在网页端创建分享时，客户端「投稿机器人 → 投稿草稿」里就会出现对应草稿，确认后发布。

> 投稿接口只监听本机 `127.0.0.1`，脚本与客户端需要在同一台电脑上使用。
> 建议在客户端「设置 → 服务端口」固定一个端口，这样脚本地址不用随重启变化。

## 更新

覆盖安装新版 `123-helper.user.js` 后刷新 123 云盘页面即可。最新版本随 [123Cloud 仓库](https://github.com/weige146/123Cloud) 一起更新，版本号见脚本头部 `@version`。
