# 123 助手（123-helper.user.js）

## 脚本用途与适用场景

123 助手是一个 [Tampermonkey](https://www.tampermonkey.net/) 油猴脚本，增强 **123 云盘网页端**的文件、分享与秒传管理，并可和 [123Cloud 桌面客户端](https://github.com/weige146/123Cloud)联动实现一键投稿与影库搜索转存。

适合这些场景：

- 日常管理网盘文件：全盘搜索、批量重命名、按条件清理文件与空目录；
- 整理追剧 / 电影库：按 TMDB 中文标题自动命名剧集与电影，季集错位自动校准，兼容 MoviePilot 二级分类归档；
- 资源分享与搬运：生成 / 转存秒传（含二级秒传短链接）、批量分享、分享页免登录导出秒传 JSON；
- 配合 123Cloud 客户端：网页端创建分享后自动推送为客户端投稿草稿（别人的分享直接进搬运队列），随时随地搜索客户端影库并一键转存。

**适用页面**：123 云盘网页端（123pan.com / .cn 及 123684 / 123865 / 123912 / 123635 等域名）+ 123 公开分享页。版本号以脚本头部 `@version` 为准。

## 核心功能

### 文件页增强

- **全盘搜索**：不受当前目录限制，直接搜索整个云盘
- **右键 / 工具栏入口**：批量重命名、媒体整理、文件清理、秒传工具箱、批量分享
- **文件套同名文件夹**：把散落的文件一键包进同名文件夹
- **纯净模式**：隐藏网页端的推广与杂乱元素；紧凑表格行、隐藏「备份」文件夹
- **液态玻璃主题**：跟随系统 / 浅色 / 深色

### 批量重命名

- 规则链自由组合：查找替换（支持正则、区分大小写）、模板编号（`{name}` / `{n}`、起始编号与位数、前后缀）、删除指定文本或位置范围、字符移动、大小写与全角半角转换、空格清理
- 实时预览、保留扩展名、只改文件 / 只改文件夹
- 常用组合保存与载入、重命名历史恢复
- 选中项出口按文件名自然排序，预览与编号规则不随勾选点击顺序错乱

### TMDB 媒体整理

- 自动识别电影 / 剧集，按标题或 TMDB ID 搜索，海报墙预览、媒体分组
- **剧集季集校准**：季偏移 / 集偏移手动微调；TMDB 自动校准支持季重映射（发布组按年份编号 vs TMDB 绝对季）、会员版 / 加更 / 先导片等特别篇按期数与播出日期精确匹配、命名季特别篇（如「中医季 药食同源第 1 期」按 TMDB 季名归属目标季）、文件名 `SxxEyy` 显式标记权威匹配
- 变体命名：同集多版本（上/下分部、加更版、衍生段）自动插入变体标记（在季集记号之后、分辨率等参数之前），避免同名冲突；「主标题·命名季」（如 初入职场·中医季）自动按主标题识别 TMDB 剧集；标题里的 `part1` / `第1部分` 分段标记自动剔除（重名冲突时才以 `Part01/Part02` 变体标记区分，避免后写文件被清进回收站）
- 命名模板可自定义字段（标题、年份、分辨率、编码、音轨、发布组……），电影 / 剧集文件名、媒体文件夹（`中文名 (年份) {tmdb-id}`）、季目录模板独立配置
- **自动归类媒体库**：按条件把整理后的文件移动到媒体库目录，兼容 MoviePilot 二级分类（条件 AND / OR / 排除、年份范围、兜底分类）
- 识别词体系：自定义识别词、屏蔽词、特殊发布组别名、自动识别固定映射（分辨率 / 音效 / 编码等）、**特别篇关键词映射**（先导片 / 加更 / 会员版等 17 类触发词，设置里可自行增改别名，类型名也可自由自定义，新叫法不再漏识别）
- 旁挂字幕 / nfo 等附属文件可配置清理，支持移入回收站

### 文件清理

- **条件清理**：后缀名 + 关键词 + 大小范围组合筛选，实时容量统计，勾选后批量删除
- **空目录清理**：递归检测当前目录或全盘空文件夹，批量删除
- 扫描阶段不修改云盘、不自动勾选，确认后才执行

### 秒传工具箱

- **生成秒传**：导出 123FastLink 标准 JSON 与 123FLCPV2 链接（固定 Base62 ETag 的 V2 标准格式），文件夹递归
- **扫描断点续传**：生成/二级链接的扫描进度实时落盘（含已扫文件清单和已完成目录），中断、取消、刷新页面后对同样的选择再次导出会自动续接；工具箱顶部进度卡片可「继续扫描 / 导出已扫描部分 / 放弃进度」，抢救导出时缺 Etag 的文件会剔除而不是整体报错（进度 7 天后自动过期）
- **转存断点续传**：按「目标目录 + 内容」记录已成功秒传的文件，转存中断或部分失败后重跑同一内容会自动跳过已完成项，只补剩余部分并在结果里提示跳过数量；全部成功后自动清除记录
- **链接 / 文件转存**：支持 123FastLink JSON、V1 / V2 秒传文本、`.123share`，保留目录结构导入当前目录
- **转存秒传（工具栏一键）**：文件页勾选 1 个秒传种子文件（`.123fastlink.json/.txt`）后，工具栏「转存秒传」按钮才出现，点击直接转存，无需打开工具箱
- **二级秒传**：整包内容上传为云盘种子文件（`xxx.123fastlink.json`），对外只分享一条 `123FLCPV2$%` 开头的单文件短链接；对方转存时自动秒传种子、读出内容、再转存全部文件。种子默认存在当前目录，可在秒传设置里固定到指定文件夹
- **自动识别普通 / 二级**：粘贴框、本地文件导入和勾选的云盘文件都会自动判断——单文件种子走二级还原，其余按普通秒传直接转存
- **并发按官方接口实测对齐**：秒传导入（转存）默认 32 并发——官方复用接口实测无频控（32 并发 85 req/s 全部成功）；导出扫盘默认 8 并发——官方对目录列表接口限约 15 目录/秒，拉更高不涨速，超速的频控响应（code 100011）自动退避重试，不再中止扫描
- **仅保存链接**：把已生成的秒传链接文本保存为云盘里的文本文件（与「从秒传文件获取」形成 存 ↔ 取 闭环）
- **分享链接生成 JSON**：粘贴 123 分享链接直接递归生成秒传 JSON，无需先转存；支持批量（每行一个链接），扫描进度断点续传。分享目录请求默认跨域直连 `www.123865.com` 稳定域名并以最高 32 目录并发全速扫描（该域名实测无实质限流，实测 258 req/s 零风控），万一撞上配额限速门自动冷却约 1 分钟再续扫，进度不丢、不用重头再来
- **拆分 JSON**：按目录层级或按文件数量拆分大秒传文件
- **格式转换**：`.123share` ↔ 标准 JSON 本地互转
- **影库搜索**：从 123Cloud 客户端影库接口在线加载，按一级/二级分类浏览、片名模糊搜索（300ms 防抖）与分页；作品卡片带 TMDB 海报（标题 + 年份双重校验防错图，未配置凭证时自动用内置公开 Key 兜底）；整部作品一键秒传导入当前目录，或展开勾选单个文件转存，复用转存断点续传
- **过滤设置**：生成 / 转存时按扩展名跳过 nfo、图片、字幕等
- 分享口令规范化：拦截官方分享创建响应，统一口令文本格式
- 表格勾选读取升级：直接从 123 页面 React 组件内部状态读取选中文件（含文件指纹），更准更快；跨页 / 翻页选中不丢

### 分享与一键投稿

- **批量分享**：每个顶层项单独创建分享（已有相同分享直接复用），永久有效 + 随机口令（有效期、口令长度可配），一键复制全部链接
- **分享页导出 CSV**：把自己分享列表导出表格（接口限流时自动放宽退避重试）
- **一键投稿**：分享创建后自动推送到 123Cloud 客户端——别人的分享自动进入搬运队列，自己的分享生成投稿草稿，客户端确认后发布

### 公开分享页增强

- 打开别人的 123 分享链接时：隐藏顶部拉新横幅与会员广告
- 增加「生成秒传 JSON」按钮：无需登录 123 账号，递归读取公开分享生成秒传文件（分享目录请求始终直连 `www.123865.com`，不受 share/mshare 域名限流影响）

## 安装、启用、配置与使用

### 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 任选其一：
   - 从 Greasy Fork 安装（推荐，可自动更新）：打开[脚本主页](https://greasyfork.org/zh-CN/scripts/592236-123-%E5%8A%A9%E6%89%8B)点「安装此脚本」；
   - 把 [`123-helper.user.js`](./123-helper.user.js) 直接拖入浏览器，由 Tampermonkey 接管安装；
   - 或打开 Tampermonkey 面板 →「添加新脚本」，粘贴 `123-helper.user.js` 全部内容并保存。

### 启用与更新

- 脚本默认启用，访问 123 云盘网页版自动生效；油猴菜单里有「打开 123 助手设置」「切换页面纯净版」快捷入口。
- 临时停用：Tampermonkey 面板里关掉该脚本开关即可，无需卸载。
- 更新：用新版 `123-helper.user.js` 覆盖安装后刷新页面即可（版本号见脚本头部 `@version`，最新版本随 [123Cloud 仓库](https://github.com/weige146/123Cloud) 一起更新）。

### 配置与使用

1. **打开设置**：文件页工具栏「设置」按钮，或油猴菜单「打开 123 助手设置」。常规项（纯净模式、主题、过滤后缀等）都在这里；
2. **一键投稿（可选，需 123Cloud 客户端）**：
   1. 下载并安装 [123Cloud 客户端](https://github.com/weige146/123Cloud/releases)（保持运行）；
   2. 打开客户端 **设置 → 服务端口**，查看当前端口（建议在这里固定一个端口，脚本地址就不用随重启变化）；
   3. 脚本设置页「投稿地址」（`submissionUrl`）填 `http://127.0.0.1:<客户端端口>/api/submission/submit`，例如客户端端口为 `62156` 则填 `http://127.0.0.1:62156/api/submission/submit`；
   4. 之后网页端创建分享时，客户端「投稿机器人 → 投稿草稿」里就会出现对应草稿，确认后发布；别人的分享链接则直接进入搬运队列。
3. **影库搜索（可选，需 123Cloud 客户端）**：
   1. 客户端「影库」页先导入影库文件（支持 123FastLink 标准 JSON、123pan-strm 备份、V1/V2 秒传文本、`.123share`、`[tmdb-N]` 标记），数据入库后源文件删掉也能查；
   2. 脚本「设置 → 常规」在「投稿地址」下面的「影库接口地址」填 `http://127.0.0.1:<客户端端口>`（与投稿同一个端口）；客户端影库若设置了「访问令牌」，把它填进「影库访问令牌」；
   3. 打开「秒传工具箱 → 影库搜索」，测试连接后即可按分类浏览 / 搜索 / 转存。
4. **秒传工具箱**：文件页右键或工具栏打开，按页签使用生成 / 转存 / 二级秒传 / 拆分 / 互转 / 影库搜索；
5. **批量重命名 / 媒体整理 / 文件清理**：文件页勾选文件后右键，或用工具栏入口，均先预览再执行。

## 注意事项、已知限制与常见问题

### 注意事项

- 投稿 / 影库接口只监听本机 `127.0.0.1`，脚本与客户端必须在**同一台电脑**上使用；建议在客户端固定服务端口。
- **二级秒传的种子文件请勿删除**（可在秒传设置里固定到专门文件夹），种子被删后对应的短链接就失效了。
- 扫描断点进度保存 7 天后自动过期；「导出已扫描部分」抢救导出时会剔除缺 Etag 的文件而不是整体报错。
- 首次使用涉及跨域请求（TMDB、客户端接口）时 Tampermonkey 可能弹权限确认，选「总是允许」即可。
- 版本号遵循 Greasy Fork 规则：只在上一个已发布版本基础上 +1，不跳号、不回退。

### 已知限制

- 只支持 123 云盘**网页端**，不覆盖官方桌面 / 移动客户端；
- 脚本依赖 123 页面的 DOM 与内部接口结构，官方改版后个别功能可能暂时失效，需等脚本适配；
- 公开分享页「生成秒传 JSON」只能读取分享页公开可见的内容，加密分享需先输入正确提取码；
- TMDB 识别、海报需要能访问 `api.themoviedb.org` 的网络环境。

### 常见问题（FAQ）

- **装了脚本页面没反应？** 确认 Tampermonkey 已启用且脚本开关打开；确认当前域名在适用列表内（123pan.com / .cn、123684 / 123865 / 123912 / 123635）；刷新页面；排查是否与其他 123 相关脚本冲突。
- **一键投稿后客户端没出现草稿？** 检查客户端是否在运行；「投稿地址」里的端口与客户端「设置 → 服务端口」显示的是否一致；地址必须带完整路径 `/api/submission/submit`。
- **影库搜索连接失败或搜不到？** 确认客户端影库已导入数据；「影库接口地址」端口正确；客户端设置了访问令牌时脚本里要填同一串令牌。
- **转存中断 / 部分失败怎么办？** 直接重跑同一内容，断点续传会自动跳过已成功项，只补剩余部分。
- **批量重命名改错了能撤吗？** 能，设置里的「重命名历史」可以恢复。

## 测试

测试位于 [`tests/`](./tests/)，纯 Node 运行、无浏览器、无网络依赖（`tests/package.json` 无第三方依赖；tmdb-helper 的测试才需要 jsdom）。每个 `*.test.mjs` 自包含：直接从 `../123-helper.user.js` 里按标记切出纯逻辑片段，在 `node:vm` 沙箱里用假 API 驱动。

```bash
# 跑全部（推荐）
node 油猴脚本/123-helper/tests/run-all.mjs
# 或
cd 油猴脚本/123-helper/tests && npm test

# 单独跑某一个
node 油猴脚本/123-helper/tests/fastlink-progress.test.mjs
```

任一用例失败即以非 0 退出码结束，便于接 CI。

### 覆盖范围（正常 + 异常场景）

- `fastlink-progress.test.mjs`：秒传扫描断点续传——正常推进、**中断/取消/刷新后续传**、抢救导出剔除缺 Etag 文件、转存跳过已导入
- `fastlink-export-parallel.test.mjs`：生成秒传 / 分享页导出按层并发扫描；在途计数与限流下的并发控制
- `fastlink-import-speed.test.mjs`：秒传导入提速；**异常**：`file/info` 静默截断 fileIdList 时 fileInfos 自动补查缺失 ID
- `fastlink-secondary.test.mjs`：二级秒传全链路——UTF-8 安全 MD5（中文名）、Base62 往返、二级链接构建/解析、种子上传与「存链接 → 转存完整内容」（mock API）
- `share-export-progress.test.mjs`：分享列表导出 CSV 翻页 + 进度回调；**异常**：「分享接口请求过于频繁」限流时退避重试并最终成功
- `tmdb-calibration.test.mjs`：TMDB 季集校准——会员版/加更关键字匹配路径、季重映射、期数精确匹配
- `vcb-calibration-special.test.mjs`：VCB-Studio 特别篇——SP01/NCOP/CM 等目录判定；**防误判**：正片 `[01]` 不被当特别篇
- `workplace-tcm-season.test.mjs`：「主标题·命名季」真实场景——命名季 S00 特别篇按期数匹配、变体命名插入位置
- `tmdb-title-alias.test.mjs`：标题别名（英文命名 → 英文别名；中文 → 中文别名）+ **回归两个历史 BUG**（英文兜底污染、候选自固化）
- `organize-grouping.test.mjs`：整理分组——同剧归组、衍生分组归并、变体命名去重
- `technical-fields.test.mjs`：技术字段固定映射（音频编码 AV3A 等）+ 标题截断
- `read-current-directory.test.mjs`：**异常防御**——`homeFilePath` 逗号拼接路径必须取最后一段，否则列目录接口报 ParentFileId 格式异常
- `selection-crosspage.test.mjs`：**异常防御**——跨页/翻页勾选 200+ 文件不被「只保留可见行」的旧逻辑裁成 30 个
- `rename-selection-order.test.mjs`：选中项出口按文件名自然排序，修复编号规则跟随勾选点击顺序错乱
- `library-search.test.mjs`：影库接口地址校验、token 自动附带、query 组装；**异常**：无效 etag/size 过滤
