# TMDB 助手（tmdb-helper.user.js）

## 脚本用途与适用场景

TMDB 助手是一个 [Tampermonkey](https://www.tampermonkey.net/) 油猴脚本，运行在 [themoviedb.org](https://www.themoviedb.org/)（TMDB）网站上：以「**只搜资料、方便复制、不回写页面**」为原则提供轻量搜索浮层与若干页面增强（不向官方表单写入任何数据）。

适合这些场景：

- TMDB 编辑者 / 贡献者：在 TMDB 页面快速查豆瓣 / IMDb 对应条目、复制中文名、原名、「名称 (年份)」、简介等资料去填表；
- 剧集管理员：在季编辑页批量安排单集播出日期、从各平台抓取整季分集、上传分集剧照 / 海报；
- 123 助手（同仓库 [`../123-helper/`](../123-helper/)）用户：右键悬浮球直接复制「名称 (年份) {tmdbid=…}」标记，粘贴进媒体整理里精确匹配 TMDB 条目。

**适用页面**：`themoviedb.org` 及其子域名。页面增强按页面出现：批量单集只在季编辑页、上传图片只在图片上传页、剧集组只在剧集组页，其余页面只有搜索浮层。

## 核心功能

### 搜索 + 复制（所有页面）

- **统一数据源**：豆瓣 / IMDb（经 TMDB 反查）/ 粘贴文本三个内置数据源页签，粘贴文本支持 标语/官网/IMDb/制作代码/导演/主演 等扩展标签；新数据源用 `window.TmdbHelper.registerDataSource({id,name,search,findById})` 注册即出现在来源页签
- **一键复制**：候选卡与载入后的条目都带复制按钮——名称 / 原名 / 「名称 (年份)」 / 日期 / 简介 / 全部信息（标题、年份、类型、演职员、链接等整理成清单）
- **悬浮球**：左键开关浮层（只有点击才显示，刷新/跳转绝不自动弹出）；**右键直接复制**「名称 (年份) {tmdbid=…}」（123 助手同款标记格式）；可拖拽；搜索框支持粘贴 `{tmdbid=123}` 直接载入条目
- **TMDB API Key**：IMDb 反查需要免费 v3 Key（在「IMDb」来源页签保存）；已配置时显示打码状态，可随时「更换 / 清除」

### 批量单集（仅季编辑页 `/tv/{id}/season/{n}/edit`）

- **灵活排期**：每周固定更新日（如周一、周四各两集）、固定间隔、单日多集共用日期集号连续
- **分集表格**：粘贴解析 / 导出 TSV / 断点续传提交（走官网内部接口的批量提交）
- **过滤词剔除**：粘贴解析时命中 PV/预告/花絮等关键词的行剔除，剩余集自动重编号、保留原有缺集
- **平台抓分集**：粘贴 B站 bangumi / 爱奇艺 / 腾讯视频 / 芒果TV / 优酷 剧集页链接直接抓公开接口拿整季分集（含海报/简介信息卡）；**剧名搜索**——输入剧名并行搜索红果短剧（站内接口）与 B站番剧（自动引导 buvid cookie），点选候选即抓整季分集，封面直链一键复制可直传为海报
- **从 TMDB 拉取本季**：官方 API 读整季标题/日期/时长/简介/剧照直链，按集号合并进表格、只补空字段不覆盖手填内容
- **分集缩略图直传**：按 TMDB 官方图片规范（16:9、≥1280×720、JPG、禁止放大小图）抓取 → 自动去黑边 → 裁切 → 直传（`POST /image`，TvEpisode/still）；侧栏「季海报上传页」一键跳转官方季图片页

### 上传图片（仅图片上传页）

- 电影/剧集/季海报、背景图、标志、单集剧照页都支持：解析页面内嵌上传配置，粘贴图片直链抓取后直传（16:9 类自动去黑边），或本地图片按官方规范校验转换后直传

### 剧集组（仅剧集组页）

- 读取结构、创建/改名/删除剧集组与子组、勾选单集加入子组、按季集重排（官网内部接口）

### 扩展与体验

- **批量操作扩展**：`window.TmdbHelper.registerEpisodeAction({id,title,when,run})` 注册的批量动作与内置动作共用集编辑器「批量操作」区
- 豆瓣图片本地化（防盗链破图修复）、深色模式跟随系统、鸿蒙光感玻璃风 UI（磨砂透光、蓝紫渐变、面板宽度可拖拽）、`Alt+T` 隐藏/恢复悬浮球、`Esc` 关闭浮层、`Ctrl+Enter` 快捷搜索/解析
- **致谢**：批量单集的「过滤词重编号」「图片去黑边」与「平台链接抓分集」移植自 [TMDB-Import](https://github.com/fzlins/TMDB-Import)；「从 TMDB 拉取本季」思路来自 [tmdb-automation](https://github.com/x1ao4/tmdb-automation) / [tmdb-scraper](https://github.com/x1ao4/tmdb-scraper)

## 安装、启用、配置与使用

### 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 任选其一：
   - 从 Greasy Fork 安装（推荐，可自动更新）：打开[脚本主页](https://greasyfork.org/zh-CN/scripts/594907-tmdb-%E5%8A%A9%E6%89%8B)点「安装此脚本」；
   - 把 [`tmdb-helper.user.js`](./tmdb-helper.user.js) 直接拖入浏览器，由 Tampermonkey 接管安装；
   - 或打开 Tampermonkey 面板 →「添加新脚本」，粘贴 `tmdb-helper.user.js` 全部内容并保存。

### 启用与更新

- 访问 themoviedb.org 任意页面，右下角出现悬浮球即生效；`Alt+T` 可隐藏/恢复悬浮球。
- 更新：用新版 `tmdb-helper.user.js` 覆盖安装后刷新页面（版本号见脚本头部 `@version`）。

### 配置

- **TMDB API Key（可选，IMDb 反查与「从 TMDB 拉取本季」需要）**：到 [TMDB API 设置](https://www.themoviedb.org/settings/api) 免费申请 v3 Key → 打开脚本浮层 →「IMDb」来源页签 → 粘贴保存；已配置时显示打码状态，可「更换 / 清除」。
- **浮层行为**：浮层只在点击悬浮球后出现；拖拽悬浮球调整位置；`Esc` 关闭浮层。
- **平台抓分集 / 剧名搜索**：无需额外配置，直接粘贴剧集页链接或输入剧名即可（B站番剧搜索会自动引导 buvid cookie）。

### 使用速查

- **任意 TMDB 页面**：点悬浮球 → 搜索浮层（豆瓣 / IMDb / 粘贴文本）→ 候选卡 / 条目一键复制；右键悬浮球复制「名称 (年份) {tmdbid=…}」
- **季编辑页**：「批量单集」面板——排期生成 → 粘贴解析 / 平台抓分集 / TMDB 拉取本季 → 分集表格检查 → 批量提交 → 缩略图直传
- **图片上传页**：「上传图片」——粘贴直链抓取直传，或本地图片校验转换后直传
- **剧集组页**：「剧集组」——增删改组与子组、勾选单集入组、按季集重排

## 注意事项、已知限制与常见问题

### 注意事项

- 直传（分集缩略图 / 上传图片 / 剧集组管理）使用你在浏览器里的 TMDB 登录态，**请先在网页端登录 TMDB**；提交类操作走官网内部接口，请确认内容无误后再批量提交。
- 上传图片请遵守 TMDB 官方图片规范：16:9 剧照 ≥1280×720、JPG、禁止放大小图；脚本会自动去黑边并居中裁切，但源头图太糊无法补救。
- IMDb 反查走 TMDB 官方 API，Key 只保存在脚本本地存储（`GM_getValue`），不会上传到第三方。
- 版本号遵循 Greasy Fork 规则：只在上一个已发布版本基础上 +1，不跳号、不回退。

### 已知限制

- 脚本**不向 TMDB 页面回写任何数据**——对照填写、字段绑定、向导自动填充均已移除，只提供搜索与复制；
- 平台抓分集依赖 B站 / 爱奇艺 / 腾讯 / 芒果 / 优酷 / 红果的公开接口，平台改版或加风控时可能暂时失效，需等脚本适配；
- 红果短剧 / B站番剧的剧名搜索覆盖站内能搜到的内容，搜不到的剧只能手动粘贴链接；
- TMDB 页面结构改版可能影响面板出现位置，页面功能只在对应页面出现，其他页面只有搜索。

### 常见问题（FAQ）

- **悬浮球不见了？** 可能被 `Alt+T` 隐藏了，再按一次 `Alt+T` 恢复；确认当前域名是 themoviedb.org。
- **IMDb 来源搜索报 401？** API Key 无效或没保存；到「IMDb」页签重新粘贴有效的 v3 Key。
- **浮层刷新页面后自己弹出来？** 不会——浮层只在点击悬浮球后出现，若遇到自动弹出请到 [Issues](https://github.com/weige146/123Cloud/issues) 反馈。
- **批量提交到一半断了？** 分集列表支持断点续传提交，重新打开面板继续即可，已成功的集不会被重复提交。
- **想加自己的数据源 / 批量动作？** 在控制台或其他脚本里调用 `window.TmdbHelper.registerDataSource({id,name,search,findById})` 或 `window.TmdbHelper.registerEpisodeAction({id,title,when,run})`。

## 测试

测试位于 [`tests/`](./tests/)，从 `../tmdb-helper.user.js` 里按标记切出片段，在 `node:vm` 沙箱里跑，不需要浏览器、不需要 TMDB 账号（除豆瓣解析用 jsdom 外不联网）。依赖本目录 `package.json` 里的 jsdom（`node_modules` 已随仓库安装；缺失时先 `npm install`）。

```bash
# 跑全部（推荐）
node 油猴脚本/tmdb-helper/tests/run-all.mjs
# 或
cd 油猴脚本/tmdb-helper/tests && npm test

# 单独跑某一个
node 油猴脚本/tmdb-helper/tests/tmdb-helper.test.mjs      # 纯逻辑回归
node 油猴脚本/tmdb-helper/tests/tmdb-ui-smoke.test.mjs    # jsdom UI 冒烟
```

任一用例失败即以非 0 退出码结束，便于接 CI。

### 覆盖范围（正常 + 异常场景）

- `tmdb-helper.test.mjs`：纯逻辑回归——豆瓣桌面页 HTML 解析器（正常条目 + **异常**：缺字段/异常结构）、排期引擎（每周固定日、固定间隔、单日多集）、统一数据源抽象、字段匹配与 payload 构建
- `tmdb-ui-smoke.test.mjs`：jsdom 里引导面板并遍历各页面上下文与视图——确认默认视图 = 搜索、批量单集只在季编辑器出现、剧集组只在剧集组页出现、上传只在图片页出现，关键交互（搜索 + 复制）不抛错
