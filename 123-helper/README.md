# 123 助手（123-helper.user.js）

123 助手是一个 Tampermonkey 用户脚本，运行在 123 云盘网页端与公开分享页，增强文件管理、媒体整理、分享与秒传搬运能力；与 [123Cloud 桌面客户端](https://github.com/weige146/123Cloud)配合使用时，还可以在网页端一键投稿、随时搜索客户端影库并转存。

- 适用于 123pan.com / .cn 及 123684 / 123865 / 123912 / 123635 等官方域名的网页端、`user.` 登录域名与公开分享页；
- 版本号见脚本头部 `@version`，随 [123Cloud 仓库](https://github.com/weige146/123Cloud)同步更新。

## 功能

### 文件页

- 全盘搜索：不受当前目录限制，直接搜索整个云盘
- 批量重命名、媒体整理、文件清理、秒传工具箱、批量分享，均从右键菜单或工具栏进入
- 文件套同名文件夹：把散落的文件一键包进同名文件夹
- 纯净模式：隐藏网页端推广元素；紧凑表格行、隐藏「备份」文件夹
- 液态玻璃主题：跟随系统 / 浅色 / 深色

### 批量重命名

- 规则链组合：查找替换（支持正则、区分大小写）、模板编号（`{name}` / `{n}`、起始编号与位数、前后缀）、删除指定文本或位置范围、字符移动、大小写与全角半角转换、空格清理
- 实时预览、保留扩展名、只改文件或只改文件夹
- 常用组合保存与载入、重命名历史恢复
- 选中项按文件名自然排序，预览与编号不随勾选点击顺序错乱

### TMDB 媒体整理

- 自动识别电影 / 剧集，按标题或 TMDB ID 搜索，海报墙预览、媒体分组
- TMDB 替代源：无法直连 api.themoviedb.org 时，在「设置 → TMDB」填写第三方反代地址（填到含 `/3` 为止，只填域名自动补 `/3`），API 请求全部改走替代源
- 整理策略（每个剧集分组一键切换）：
  - 默认策略：按文件名 / 文件夹正常识别季集
  - 单季顺序拆多季：适用「龙珠Z」类动画，按真实分季结构把每集对号入座拆到正确的季并重新编号，缺集不会错位，超出总集数顺延到最后一季
  - 单季跳序拆多季：适用「海贼王」类动画，绝对集号不变，只按真实分季结构的累计区间改季号
  - 多季合并一季：适用「狐妖小红娘」（TMDB 一季、文件分 S1-S13）类动画，按真实分季结构把每季折算成全作累计集数合并进单季（S13E05 → S01E172），只整理其中一季也能算对；无真实数据时退回顺序累加
  - TMDB 剧集组：按官方剧集组（DVD 顺序、绝对顺序、故事线）整理，支持原始季集 / 绝对集号 / 播出日期匹配
- 动漫拆分/合并的真实分季数据：拆分与合并策略可从三个数据源选一个——CureTMDb 社区分季表（人工维护）、Bangumi 期结构（沿「续集」关系自动串期，走公共反代 bgmapi.anibt.net，官方 api.bgm.tv 被墙也能用，失败自动回退官方域名；兼容国产动画 / 网盘番的 WEB 平台条目与「系列名+期号」式命名）、TMDB 官方分季（兜底）。打开策略弹窗就会预取数据，弹窗里每个数据源都会列出「S1 24集 · S2 23集…」供核对后再应用，Bangumi 没匹配到会说明原因，结构缓存 24 小时；集号在结构里本来就合法的文件原样保留，单季合并型作品（如 366 集一季）会拦截并提示改用合并策略而不硬拆
- 电影合集归档：识别 `belongs_to_collection` 后按「合集名 / 电影名（年份）」聚合，全局默认开关加分组级覆盖
- 目录形态识别：认得「01 郭女侠怒砸同福店 佟掌柜秒点迷路人」这类「集号+集名」命名——文件名里没有剧名时自动拿所在文件夹名当剧名、开头数字当集数，整季并成一组而不是逐集拆组；「怪物史瑞克 / 怪物史瑞克2 / 3 / 4」这类一片一目录的续作合集勾最上层目录整理时，按子目录各认各的电影（看目录名里的年份或 TMDB 标记区分），不会把续作全部改名成第一部的名字；标题像但年份对不上的也不硬合并
- 电视台录制命名识别：【四川卫视4K超高清频道 故乡几万里】这种「频道名+剧名挤在同一个括号里」的命名直接认出剧名，SCTV-4K / CCTV-8 这类频道代码不会粘在片名前面；【重温经典频道】黑猫警长、[字幕组]番名 这类标记括号也只当标记；国产 4K 录播的技术字段认全（AVS2/AVS3 编码、UHDTV 超高清电视录制、HLG），音频 DD2.0/DD5.1 不再被误认成杜比全景声 Plus
- 季集校准：季偏移 / 集偏移手动微调；季重映射、会员版 / 加更 / 先导片等特别篇按期数与播出日期精确匹配、`SxxEyy` 显式标记权威匹配
- 季集编号高亮：预览列表中原文识别片段与最终写入的 `SxxEyy` 双向红色标注，便于人工核对
- 变体命名：同集多版本自动插入变体标记；「主标题·命名季」按主标题识别；分段标记自动剔除；多分段电影（Part 1/Part 2）的 Part 标记按 Emby/Plex 堆叠规范插在「片名.年份」之后、技术字段之前，媒体库才能把两段堆叠成一部电影
- 同名冲突兜底：预览与执行两阶段核对目标目录，撞名文件跳过并移入回收站（可还原），不产生「名字(1)」副本；执行复查每个目标目录只列举一次，不拖慢整理
- 命名模板自定义：标题、年份、分辨率、编码、音轨、发布组等字段，电影 / 剧集 / 媒体文件夹 / 季目录模板独立配置
- 自动归类媒体库：按条件移动到媒体库目录，兼容 MoviePilot 二级分类
- 识别词体系：自定义识别词、屏蔽词、发布组别名、特别篇关键词映射（17 类触发词，别名可增改）、内置 PT 发布组替换表（24 条）
- 旁挂字幕 / nfo 等附属文件可配置清理，支持移入回收站

### 文件清理

- 条件清理：后缀名 + 关键词 + 大小范围组合筛选，实时容量统计
- 空目录清理：递归检测当前目录或全盘
- 扫描阶段不修改云盘，确认后才执行

### 操作记录与一键还原

- 媒体整理与批量重命名执行成功后自动记录，按刮削文件夹名聚合，列表自然排序
- 记录详情可展开文件清单：原文件名、新文件名、目标路径、校准季集、状态
- 一键还原：改名 + 移动反向重放，被清空的来源目录自动重建；已还原的跳过、被再次动过的标注跳过，不碰手动整理过的文件
- 回收站还原：整理时清理进回收站的旁挂文件同样可还原
- 入口：油猴菜单「打开 123 助手操作记录」

### 秒传工具箱

- 生成秒传：导出 123FastLink 标准 JSON 与 123FLCPV2 链接（Base62 ETag），文件夹递归
- 转存：支持 123FastLink JSON、V1 / V2 秒传文本、`.123share`、二级秒传短链，保留目录结构导入当前目录；路径自动清理（连续空格折叠、非法字符删除），点开头的隐藏文件等无法处理的条目跳过并计数，不再因个别坏条目中止整包
- 自适应限速门：目录列举与秒传写入各自有一把全局门，按「请求间距」控制速率而不是靠并发硬顶；撞频控（`100011` / 429 / "请求过于频繁"）时全部门一起冷却并放慢间距、结束后自动续跑，门的水位随断点落盘，续跑不会带着刚触发的风控满速再撞
- 请求数削减：目录列举每页 500 条（服务端异常时自动降回 100），建目录改为「父目录名 → ID 索引 + 新建覆盖表」，不再为每个子目录全量翻页查父目录
- 接口线路自动探测：任务开始前探测页面域名 / `www.123865.com` / `api.123278.com` 哪条最快且不被限流，运行中一条线路连续撞限会自动换道。线路由脚本自己选，设置页不提供手动选项；若怀疑线路选错，在秒传设置点「恢复默认」即可清掉线路偏好与探测缓存，下一次任务重新探测
- 并发只是流水深度：默认域名 32 起、直连线路按「写入并发」设置（≥16 生效，否则 24），实际速率由限速门保证，调高并发不会再提高瞬时请求速率
- 运行明细：进度条实时显示目录数 / 文件数 / 累计体积 / 处理速率 / 剩余时间 / 当前条目与频控冷却倒计时，可展开最近 30 行明细日志；长任务支持「暂停 / 继续」（在途请求跑完即停在门口，断点不丢）
- 秒传未命中单列一桶：云端没有同哈希文件的条目记为「未命中」而不是失败，结果页可按状态筛选并导出明细 CSV；有未命中时保留断点，重跑只补未命中那些
- 大文件流式转存：本地秒传 JSON 按块流式解析，GB 级、千万级条目不卡死页面；转存断点分片存档，中断后重跑自动跳过已完成项
- 二级秒传：整包内容上传为云盘种子文件，对外只分享一条短链；对方转存时自动还原全部文件。种子默认存当前目录，可在秒传设置里固定文件夹
- 二级链接自动投稿：点「生成二级链接（短链）」成功后，自动把短链直投给客户端（与分享链接直投同一接口）生成投稿草稿；频道帖带「秒传链接」复制按钮，不再附带秒传 JSON 文件。需要在「设置 → 分享与秒传 → 投稿地址」填好客户端接口；没配置或推送失败只提示，不影响已生成的链接
- 扫描断点续传：导出扫描进度实时落盘，中断、刷新后自动续接；抢救导出剔除缺 Etag 的文件（进度 7 天过期）
- 工具栏常驻「秒传」按钮：无勾选点击打开工具箱，勾选秒传种子文件时点击直接转存
- 分享链接生成 JSON：粘贴 123 分享链接递归生成秒传 JSON，支持批量；分享目录请求直连 `www.123865.com` 全速扫描，撞限流自动冷却续扫
- 拆分 JSON：按目录层级、文件数量或季集 / 剧名拆分大秒传文件
- 格式转换：`.123share` 与标准 JSON 本地互转
- 影库搜索：连接 123Cloud 客户端影库接口，按分类浏览、模糊搜索、整部作品一键转存或勾选单文件转存。客户端按文件夹名里的 `{tmdb-N}` 标记聚合作品与整理分类——导入前先给网盘目录打好标记（用本脚本的「TMDB 媒体整理」即可）
- 过滤设置：生成 / 转存时按扩展名跳过 nfo、图片、字幕等
- 仅保存链接：把秒传链接文本保存为云盘文本文件

### 分享与投稿

- 批量分享：每个顶层项单独创建分享（相同分享自动复用），永久有效 + 随机口令，一键复制全部链接
- 一键投稿：分享创建后自动推送到 123Cloud 客户端——别人的分享进入搬运队列，自己的分享生成投稿草稿
- 分享页导出 CSV：导出自己的分享列表（限流时自动退避重试）

### 登录会话复用

同一账号在多个浏览器登录会在 123 云盘新增多台设备。脚本支持把一个浏览器里的登录会话导出，在其余浏览器导入，全部浏览器共用同一会话：

1. 前提：运行 123Cloud 客户端，脚本「设置 → 分享与秒传」填好影库接口地址（与影库访问令牌）；
2. 推送：在已登录的浏览器里，通过油猴菜单「推送登录会话到客户端」把会话存档到客户端；
3. 拉取：在其他浏览器打开 123 云盘任意页面（含 `user.123pan.cn` 登录页，未登录状态即可），通过油猴菜单「从客户端拉取登录会话」——脚本会自动跳到推送来源的网盘页（如 `yun.123pan.cn`）写回登录；在网盘页拉取则直接生效；
4. 会话过期后在已登录浏览器重新推送一次即可。入口只有油猴菜单（Tampermonkey 扩展图标里），设置面板不设会话 UI——登录页 `user.123pan.cn` 没有面板，菜单在所有页面都可用。

### 公开分享页

- 隐藏顶部拉新横幅与会员广告
- 分享页搜索：直接在官方搜索框输入关键词，脚本同步搜一份并弹出结果面板（走 123 官方搜索接口，大分享秒出结果），支持类型筛选、点文件夹结果缩小搜索范围；勾选结果可生成秒传 JSON（文件自带特征值不用扫描，文件夹只扫该文件夹），结果可导出 CSV；按回车出官方搜索结果页时面板自动收起，官方结果里勾选行后可用旁边的「生成秒传 / 导出 CSV」按钮处理勾选项
- 「生成秒传 JSON」按钮：无需登录 123 账号，递归读取公开分享生成秒传文件（加密分享需先输提取码）

## 使用方式

### 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 任选其一：
   - 从 Greasy Fork 安装（推荐，自动更新）：打开[脚本主页](https://greasyfork.org/zh-CN/scripts/592236-123-%E5%8A%A9%E6%89%8B)点「安装此脚本」；
   - 把 `123-helper.user.js` 拖入浏览器，由 Tampermonkey 接管安装；
   - 或在 Tampermonkey 面板新建脚本，粘贴 `123-helper.user.js` 全部内容保存。

### 更新

用新版 `123-helper.user.js` 覆盖安装后刷新页面。Greasy Fork 安装的会自动更新；本地覆盖安装的以脚本头部 `@version` 为准。

升级后首次打开任意网盘页面会弹一次「更新内容」，点「我已知晓」后同版本不再打扰；随时可从油猴菜单「查看 123 助手更新内容」回看。

### 基本使用

1. 访问 123 云盘网页版，文件页工具栏出现「秒传」「设置」等入口；
2. 批量操作：勾选文件后右键，或使用工具栏按钮，均先预览再执行；
3. 秒传工具箱：工具栏「秒传」按钮打开，按页签使用生成 / 转存 / 二级秒传 / 拆分 / 互转 / 影库搜索；
4. 设置：文件页工具栏「设置」或油猴菜单「打开 123 助手设置」；
5. 会话复用：见上文「登录会话复用」一节。

### 与 123Cloud 客户端联动（可选）

1. 安装并保持 [123Cloud 客户端](https://github.com/weige146/123Cloud/releases)运行，「设置 → 服务端口」固定一个端口；
2. 一键投稿：脚本设置页「投稿地址」填 `http://127.0.0.1:<端口>/api/submission/submit`；
3. 影库搜索：脚本设置页「影库接口地址」填 `http://127.0.0.1:<端口>`，客户端影库设置了访问令牌时填同一串令牌；
4. 客户端「影库」页导入影库数据后，即可在网页端随时搜索转存。

## 注意事项与已知限制

- 投稿 / 影库接口只监听 `127.0.0.1`，脚本与客户端必须在同一台电脑上；建议固定客户端服务端口。
- 二级秒传的种子文件删除后对应短链失效；可在秒传设置里固定到专门文件夹。
- 扫描断点进度 7 天后过期；抢救导出会剔除缺 Etag 的文件而非整体报错。
- 跨域请求（TMDB、客户端接口、镜像线路）首次使用时 Tampermonkey 可能弹权限确认，选「总是允许」。
- 网盘登录态只存在各网盘页域名（`www/yun.*` 官方域名）自己的 localStorage 里，登录页/其他页面写入无效；拉取时脚本自动跳到推送来源的网盘页完成写入（会话暂存 10 分钟内有效）。
- 「推送/拉取到客户端」需要运行 123Cloud 客户端并填好影库接口地址；会话存档在客户端本机，鉴权与影库访问令牌同门。客户端的 123 OpenAPI token 与网页端会话不互通（官方无转换通道），因此客户端只能中转会话、不能凭空生成网页登录态。
- 只支持 123 云盘网页端，不覆盖官方桌面 / 移动客户端；官方页面改版后个别功能可能需要适配。
- TMDB 识别与海报需要能访问 `api.themoviedb.org`（或配置替代源）。
- 版本号遵循 Greasy Fork 规则：在上一个已发布版本基础上 +1，不跳号、不回退。

## 常见问题

- **装了脚本页面没反应？** 确认 Tampermonkey 与脚本开关已启用、域名在适用列表内，刷新页面，排查其他 123 相关脚本冲突。
- **一键投稿后客户端没出现草稿？** 确认客户端在运行、投稿地址端口与客户端「服务端口」一致、地址带完整路径 `/api/submission/submit`。
- **影库搜索连不上？** 确认客户端影库已导入数据、接口地址端口一致、访问令牌填写一致。
- **转存中断 / 部分失败？** 重跑同一内容，断点续传自动跳过已成功项。
- **重命名改错了？** 设置里的「重命名历史」可以恢复。
- **导入秒传 JSON 提示跳过了很多条？** 脚本会自动清理路径（连续空格折叠、非法字符删除）并跳过无法处理的条目（点开头隐藏文件、坏 Etag、坏大小），结果页有分类统计；只影响坏条目，其余文件正常导入。
- **进度条出现「频控冷却中，Xs 后自动继续」？** 这是内置限速门在正常工作：撞上限流时全部请求一起歇一会儿、放慢间距后自动续跑，不需要你干预，也不会像以前那样整轮失败。持续只降不升，可在秒传设置里换一条接口线路。
- **秒传结果里的「未命中」是什么？** 云端没有可复用的同哈希文件，这一条本次没有转存（不是失败）。断点会保留，重跑只补这些未命中条目。
