# TMDB 编辑规则（实测沉淀，违反会翻车或被回滚/封禁）

## 别名核对（防重复条目，建条前必做）

国内平台常买版权后改名上线，**按来源名搜 TMDB 搜不到 ≠ 不存在**：

1. 搜不到来源名时，先查百度百科/豆瓣确认**原名/别名**（豆瓣「又名」、百科信息栏），再用原名搜 TMDB。
2. 比对首播年份与简介——简介一字不差就是同一部（如《朱元璋惩贪》=《洪武大案》2011；《女孩冲冲冲》=《向周星驰致敬先》2009）。
3. 平台上线日 ≠ 首播日（B站《朱元璋惩贪》2021-12-30 上线，原剧 2011 首播）。
4. 拿不准**先问用户**「是不是同一部」，宁慢勿错，不直接新建。
5. 误建重复条目**无法自助删除**（无删除接口，需管理员），所以必须先核对。

## 日期规则

- **查不到逐集真实播出日，就把该集 `air_date` 留空**（接口接受 `""`），绝不瞎填推算值。
- **不要按「每周一集」推算国产剧日期**——周更规律只适合美剧/日番；国产剧多为日更、多集连播或全集上线。
- 国内平台 `pub_time`/上线日期 ≠ 真实首播日（B站常是批量上线时间），只能当线索。真实首播日去百科/豆瓣确认。
- 有确认的首播日只填第 1 集，其余留空；TMDB 显示空日期集是正常的。
- 官方 air-dates 规则（/bible/air-dates）：日期是「本地时区当日」的真实日历日；同一天播多集共用同一日期、集号连续；允许未来日期（未播出集会被锁定到临近播出）。
- 确有播出规律的排期（周更/固定间隔/单日多集）可让 skill 生成，但要给用户过目。

## 图片规范（/bible/image）

| 类型 | 比例 | 最低 | 最高 | 格式 |
|---|---|---|---|---|
| 海报 poster | 2:3（容差 0.02） | 500×750 | 2000×3000 | JPG |
| 背景图 backdrop / 剧照 still | 16:9（容差 0.02） | 1280×720 | 3840×2160 | JPG |
| 标志 logo | 无 | 200×50 | 2000×2000 | PNG（透明底） |
| 人物头像 profile | 2:3 | 300×450 | 2000×3000 | JPG |

- **禁止放大小图**：低于最低分辨率直接换图，不要硬拉（脚本会报错拦截）。
- 比例不对**裁剪**不许拉伸；16:9 类先自动去黑边再裁；「正面+背面」横向拼图封面用取左/右半裁，避免拼缝。
- 剧照要求干净画面：无水印、无 logo、无字幕截帧尽量避开。
- 上传前一律过 `prep_image.py transform`（自动按上表校验+处理）。
- 图片要有意义：不要上传与条目无关、重复、模糊的图；同图多语言版本只传一张。

## 翻译规范（中文化）

- 目标语言 `zh-CN`（简体）。标题优先用**官方/发行方中文名**（豆瓣「又名」、片头字幕、发行海报），没有公认译名再拟，拟了要在编辑摘要里给依据。
- 简介翻译要准确通顺，不逐字硬翻；人名/地名前后一致。不确定的内容宁可留空给后续贡献者。
- 别填机器翻译痕迹明显的内容——会被其他贡献者投票回滚。
- 尊重已有翻译：有 zh-CN 翻译且无错就不动；纠错在编辑摘要里说明理由。

## 演职员规范

- 搜人物 `search/remote/person` 后**必须核对 `known_for` 作品**再挂接——同名演员极多，挂错人比缺人更糟。
- 人物不存在才新建；已有条目补头像用 `profile` 规范。
- 角色名用剧中译名（主演）；职员按职位分类（导演/编剧/制片…），顺序按片头署名。

## 编辑礼仪

- 写请求间隔 300–800ms；大批量任务拆批跑（单条目单季为宜），不要一晚灌全站。
- **先读后写**：只补缺失、只纠明确错误；不要为「更好看」重写别人已填内容，避免编辑战。
- 编辑摘要写清楚来源（如「依据：豆瓣条目 xxx / 官方微博公告」），方便审核与追溯。
- 批量行为异常会被 TMDB 反滥用系统盯上，重则封号：单日编辑量节制，失败不要无脑重试。
- 所有写入在执行前产出计划给用户确认；用户是贡献者，责任在账号。
